Install Firefox add-ons

This local page never sends profile data anywhere. Opened inside the new Firefox profile, each official Mozilla Add-ons link requests an extension installation. Review the permissions and click Add to approve. These links target versions observed in the author's uploaded profile; they may become unavailable, so use the current add-on listing on addons.mozilla.org if necessary. You can skip any extension. Mozilla built-in components and themes are omitted.
